----------------------------------------------------------
   ยังไม่มีโปรแกรม Python ในเครื่องนี้
----------------------------------------------------------

กรุณาติดตั้ง Python ก่อน แล้วค่อยเปิดไฟล์ "ติดตั้ง.bat" นี้อีกครั้ง

   1. เข้าเว็บ  https://www.python.org/downloads/
   2. กดปุ่มดาวน์โหลด Python (เลือกเวอร์ชัน 3.13)
   3. เปิดไฟล์ที่ดาวน์โหลดมา
   4. *** สำคัญมาก *** ก่อนกด Install ให้ติ๊กช่อง
      "Add python.exe to PATH" ที่อยู่ด้านล่างของหน้าต่าง
   5. กด Install แล้วรอจนเสร็จ
   6. กลับมาดับเบิลคลิกไฟล์ "ติดตั้ง.bat" อีกครั้ง
