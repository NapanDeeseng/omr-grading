----------------------------------------------------------
   ยังไม่มีโปรแกรม Python ในเครื่องนี้
----------------------------------------------------------

กรุณาติดตั้ง Python ก่อน แล้วค่อยเปิดไฟล์ "ติดตั้ง.bat" นี้อีกครั้ง

   1. เข้าเว็บ  https://www.python.org/downloads/windows/
   2. หาหัวข้อ Python 3.14 แล้วกด Windows installer (64-bit)
      (แนะนำ 3.14 เพราะทดสอบกับระบบนี้แล้ว)
   3. เปิดไฟล์ที่ดาวน์โหลดมา ชื่อประมาณ python-3.14.x-amd64.exe
   4. *** สำคัญมาก *** ก่อนกด Install ให้ติ๊กช่อง
      "Add python.exe to PATH" ที่อยู่ด้านล่างของหน้าต่าง
   5. กด Install Now แล้วรอจนขึ้นว่า Setup was successful
   6. กลับมาดับเบิลคลิกไฟล์ "ติดตั้ง.bat" อีกครั้ง

ถ้าแน่ใจว่าติดตั้ง Python ไปแล้วแต่ยังขึ้นข้อความนี้
   - ปิดหน้าต่างนี้ แล้วดับเบิลคลิก "ติดตั้ง.bat" ใหม่อีกครั้ง
   - ถ้ายังไม่หาย แปลว่าตัวติดตั้งยังทำงานไม่จบ หรือเป็นรุ่นเก่ากว่า 3.11
     ให้ติดตั้ง Python 3.14 ตามขั้นตอนด้านบนอีกครั้ง
