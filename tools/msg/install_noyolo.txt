----------------------------------------------------------
   ติดตั้งส่วนเสริม AI ช่วยตรวจไม่ได้ (ข้ามได้)
----------------------------------------------------------

ส่วนเสริมนี้ยังไม่รองรับ Python รุ่นที่ติดตั้งในเครื่องนี้
กำลังติดตั้งเฉพาะส่วนที่จำเป็นแทน

ระบบยังตรวจข้อสอบและออกคะแนนได้ครบถ้วนเหมือนเดิม
ต่างกันแค่ไม่มีตัวช่วยชี้จุดที่น่าสงสัยเพิ่มให้เท่านั้น

ถ้าต้องการส่วนเสริมนี้ด้วย ให้ติดตั้ง Python เวอร์ชัน 3.14
แล้วดับเบิลคลิก "ติดตั้ง.bat" ใหม่อีกครั้ง
